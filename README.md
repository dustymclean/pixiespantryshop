# pixiespantryshop.com

Static site generated by `hub/build.py`, served by GitHub Pages from the `gh-pages` branch.

## Update everything from a fresh affiliate export

```bash
python3 hub/import_export.py /path/to/Pixies    # the unzipped Awin + Impact export folder
hub/deploy.sh                                    # build + audit + dry run
hub/deploy.sh --push                             # go live
```

Never commit the raw export (it contains account identifiers); `.gitignore` blocks it.

## Where things live

| What | File |
|---|---|
| Partner registry (522, from the export) | `hub/data/partners.json` |
| Offers + history | `hub/data/offers.json` |
| Your personal codes | `hub/data/personal_codes.json` |
| **Per-partner description, category, product lines** | `hub/data/notes/0*.json`, `sells_*.json` |
| Shopper-facing brand names | `hub/data/notes/brands.json` |
| Homepage boxes, prices, store links | `hub/data/store.py` |
| Hub cards (the three doors) | `hub/data/content.py` |
| Banner rotation rules | `hub/ads.py` |

A new partner with no note fails the build on purpose, so nothing ships without a description.

## Dates

"Verified" on every page is the export date (`hub/data/meta.json`), never the build day. Rebuilding
without fresh data does not re-stamp old offers as new.

## Banners

One labelled box slot per page. Every advertiser gets equal exposure (median number of creatives
each, best first); a brand's own page shows its own banner. Impression pixel fires only when visible.
